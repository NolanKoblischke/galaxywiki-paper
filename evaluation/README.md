# Evaluation

Run `uv run reproduce.py` from the repository root to summarize these saved results.

`quote_matches.csv` contains quotation matching outcomes. Strict recovery counts literal and normalized contiguous matches. Source texts are not bundled, so matching is not rerun.

`manual_review.csv` contains 60 sampled records assessed by one expert author. Initial answers defaulted to yes. Six cases received later agent-assisted reassessment. Final labels support 58 identities, with two uncertain cases retained. Three supported identities have precision concerns. These judgments do not establish the draft’s 57/60 coordinate-support claim or uniform astrometric accuracy.
